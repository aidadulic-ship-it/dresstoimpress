# Aida's Closet

Persönlicher Outfit-Assistent als Web-App. Aus Wetter, Anlass, Körpergefühl und Tagesstimmung schlägt sie **genau einen Look** vor.

- Regelbasiert, mit festen Temperatur-Regeln
- Wäsche-Status pro Teil, Tauschen, Historie, Lernfunktion
- Rein lokal: keine Server, keine Weitergabe von Daten, Speicherung im Browser
- Single-File HTML/CSS/JavaScript, keine Abhängigkeiten
- Mobile-first, Design in eigener Markenpalette (Aubergine, Magenta, Rosé)
